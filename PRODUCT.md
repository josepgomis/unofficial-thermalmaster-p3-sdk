# Product context

Independent community SDK for Thermal Master P3, Python 3.8+, Windows/Linux,
optional OpenCV technical viewer and ROS 2 Foxy/Humble/Jazzy adapters.
Primary audience: developers acquiring radiometric data for robotics and experiments.
Success: a newcomer follows USB setup, installs the package and captures temperatures
without modifying library code. Capture and recording precede advanced perception.
The user selected a lightweight technical viewer, not a Qt application.
